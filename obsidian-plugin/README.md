# AueXUE Obsidian 插件

在 Obsidian 内管理 AueXUE 站点：发布文章、维护友链、公告、关于页、相册，以及 **HTML 文件** 与 **站点设置**。

## 安装

1. 从 Release 下载 `obsidian-AueXUE.zip`；
2. 解压到 `<你的库>/.obsidian/plugins/aiovtue-valaxy-sync/`；
3. Obsidian → 设置 → 第三方插件 → 启用 AueXUE。

目录中应包含三个文件：`main.js`、`manifest.json`、`styles.css`。

## 配置

在插件设置里填写站点地址与认证信息：

| 项 | 说明 |
|---|---|
| 站点地址 | 例如 `https://blog.me-i.top`，不要带结尾斜杠 |
| API Token | 与站点环境变量 `ADMIN_API_TOKEN` 一致，见于网站后台「环境变量」配置 |

## 管理面板

左侧「AueXUE 管理」打开面板，模块与网站后台一一对应：

| 模块 | 对应网站后台 | 说明 |
|---|---|---|
| 文章管理 | 文章管理 | 新建、编辑、发布、删除 |
| 友链管理 | 友链管理 | 分组与条目 |
| HTML 文件 | HTML 文件 | 独立 HTML 页面，发布后 `/slug.html` 可访问 |
| 相册管理 | 相册管理 | 相册与页面设置 |
| 公告栏管理 | 公告栏管理 | 分组与行内容 |
| 关于页 | 关于页 | Markdown 源码编辑 |
| 站点设置 | 站点设置 | 站点名称、头像、主题色、首页 hero、顶栏页脚、列表页样式、社交链接、打赏 |

> 站点设置保存后前台刷新即生效；首次进站的加载动画与预渲染标题在下次站点构建时更新。
